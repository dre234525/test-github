# Калькулятор личных финансов

## Описание

Простое консольное приложение на Python для учёта личных финансов.

## Установка и запуск


```bash
git clone https://github.com/dre234525/test-github.git
cd test-github
python app.py
```

## Использование

После запуска появляется меню:

```
1. Добавить доход
2. Добавить расход
3. Список операций
4. Баланс
0. Выход
Выберите пункт:
```
Нужно будет выбирать нужную цифорку

## Функционал
- [x] Добавление дохода и расхода с суммой, категорией и датой
- [x] Просмотр списка всех операций
- [x] Вывод баланса (доходы − расходы)
