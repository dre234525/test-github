# Калькулятор личных финансов

## Описание

Простое консольное приложение на Python для учёта личных финансов. Позволяет вводить доходы и расходы, указывать категорию и дату, просматривать список операций и текущий баланс. Работает без сторонних библиотек, текст в консоли выводится розовым цветом.

## Установка и запуск

Требуется Python 3.6 или новее. Сторонние библиотеки не нужны.

```bash
git clone https://github.com/dre234525/test-github.git
cd test-github
python app.py
```

## Использование

После запуска появляется меню:

```
=== Калькулятор личных финансов ===
1. Добавить доход
2. Добавить расход
3. Список операций
4. Баланс
0. Выход
Выберите пункт:
```

Пример добавления дохода:

```
Выберите пункт: 1
Сумма: 5000
Категория: Зарплата
Дата (ДД.ММ.ГГГГ): 01.11.2026
Операция добавлена
```

Пример просмотра баланса:

```
Выберите пункт: 4
Доходы:  5000.00
Расходы: 1200.50
Баланс:  3799.50
```

## Функционал

Реализовано:
- [x] Добавление дохода и расхода с суммой, категорией и датой
- [x] Просмотр списка всех операций
- [x] Вывод баланса (доходы − расходы)
- [x] Интерактивное меню в консоли
- [x] Проверка корректности ввода суммы и даты
- [x] Розовый цвет текста в консоли

Планируется:
- [ ] Сохранение операций в файл
- [ ] Статистика расходов по категориям
- [ ] Удаление и редактирование операций
